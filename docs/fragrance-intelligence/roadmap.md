# Roadmap

## Phase 1 — Foundation (current)

Normalized schema, taxonomy seeds, catalogue endpoints, supplier loader, validation suite, deterministic vector engine, similarity and administration shell.

## Phase 2 — Governance

Alembic revision lifecycle, approval queues, source provenance per attribute, RBAC/SSO, audit events, merge tooling, object storage for imports and data-quality service-level objectives.

## Phase 3 — Intelligence

Learned vector calibration from preference outcomes, contextual reranking for season/weather/occasion/budget, collection-aware novelty, clone evidence confidence and layering safety rules. Offline evaluation will track precision@k, diversity, coverage and calibration.

## Phase 4 — Integration

Publish a stable v1 contract, event-driven inventory synchronization, consented customer profiles, cached search indices, localization and storefront widgets. Integration remains gated by privacy, security, accessibility and load testing.
