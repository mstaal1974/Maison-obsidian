# Clone intelligence methodology

A clone relationship is directional from clone to original. Similarity combines an olfactory assessment and vector evidence, expressed as 0–100 accuracy. Separate signed fields capture performance, longevity, projection and price differences; narrative differences document opening, development and dry-down.

Claims require a named source, assessment date, concentration and batch where known. At least two independent assessments are recommended before verification. Similarity does not imply equivalence, affiliation or counterfeit status. Records must use neutral language and preserve disagreement. Self-links and duplicate pairs are invalid.
